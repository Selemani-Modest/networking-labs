# Networking Labs

Hands-on CCNA labs built in Cisco Packet Tracer, with the topology, device configurations and notes for each lab. I use this repo to practise, document and troubleshoot real network scenarios while preparing for the CCNA.

## Labs

| Lab | Topic | Status |
|-----|-------|--------|
| 01 | [Static routing with VLSM (4 LANs + point-to-point link)](01-static-routing-vlsm/) | Done |

## What each lab folder contains

- `README.md`: objective, IP addressing plan, commands used and what I learned
- Topology screenshot
- Packet Tracer file (`.pkt`)
- Verification output (`show ip route`, ping results)
- Troubleshooting notes: what failed and how I fixed it

## Tools

Cisco Packet Tracer · GNS3 · Wireshark
